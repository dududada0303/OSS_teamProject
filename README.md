2026.05.22 첫번째 커밋 변경사항 :플레이어가 움직이고 플레이어가 동전에 닿으면 코인이 먹어지도록 구현

주요 구현 기능 및 로직 (CoinScript) 충돌 감지 (OnTriggerEnter): 동전 오브젝트에 Collider 컴포넌트를 부착하고 Is Trigger 옵션을 활성화하여, 플레이어가 동전을 통과할 때 충돌을 감지하도록 설정했습니다.
플레이어 식별: 충돌한 오브젝트의 이름이 "Player"인지 확인하는 조건문(if(other.name == "Player"))을 통해, 플레이어가 닿았을 때만 로직이 실행되도록 제한했습니다.

오브젝트 삭제 (Destroy): 플레이어와 충돌이 확인되면 Destroy(gameObject); 함수를 호출하여 맵에 있던 동전 오브젝트를 실시간으로 제거(파괴)합니다.

문제 해결 및 빌드 환경 정비 (영상 하단 Output 내용) 누락된 스크립트 에러 해결: 하단 콘솔 창에 뜨는 에러(Could not find file... Distance.cs, CollectionDetection.cs)를 바탕으로, 프로젝트 이동이나 병합 과정에서 유실되었던 불필요한 스크립트 레퍼런스 및 빌드 에러 요인들을 정리하여 정상적으로 컴파일이 완료되도록 정비했습니다.
