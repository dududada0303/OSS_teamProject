# OSS_teamProject
0. 최상위 폴더를 하나 만들고 그 아래 Repository 파일들을 넣습니다.
1. 유니티 허브를 실행합니다.
2. 왼쪽 메뉴에서 프로젝트 클릭 후 우측 상단의 추가 버튼을 클릭합니다.
3. 방금 압축을 풀어둔 프로젝트 폴더 자체를 클릭하고 '폴더 선택'을 눌러주세요.
5. 유니티 허브 목록에 새로 추가된 프로젝트를 클릭해서 실행합니다.
6. 유니티 화면이 열리면, 하단의 Project 창에서 Assets -> Scenes 폴더로 이동한 뒤 GameScene을 더블 클릭해 열어주시면 됩니다! 

* 유니티가 처음 파일들을 읽어오고 설정하느라 로딩시간이 조금 걸릴 수 있으니 잠시 기다려주세요.
* 스크립트는 종류별로 파일을 만들어 구분해두었습니다.

README.md 파일에 각자의 진행상황을 업데이트 할 예정이기 때문에, 이 칸처럼 구분선으로 본인만의 레이아웃을 만들어주시면 감사하겠습니다.
