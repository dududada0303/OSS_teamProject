# OSS_teamProject
OSS개론 팀 프로젝트 저장소입니다.

1. 현재 깃허브 페이지 우측 상단의 초록색 [ <> Code ] 버튼을 누른 후, [ Download ZIP ]을 클릭하여 파일을 다운로드합니다.
다운로드한 ZIP 파일의 압축을 원하시는 폴더에 풀어주세요.
유니티 허브를 실행합니다.
왼쪽 메뉴에서 프로젝트 클릭 후 우측 상단의 추가 버튼을 클릭합니다.
방금 압축을 풀어둔 프로젝트 폴더 자체를 클릭하고 '폴더 선택'을 눌러주세요.
유니티 허브 목록에 새로 추가된 프로젝트를 클릭해서 실행합니다.
유니티가 처음 파일들을 읽어오고 설정하느라 로딩 시간이 조금 걸릴 수 있으니 잠시 기다려 주세요.
유니티 화면이 열리면, 하단의 Project 창에서 Assets -> Scenes 폴더로 이동한 뒤 GameScene을 더블 클릭하여 열어주시면 됩니다! 

2. 스크립트는 종류별로 파일을 만들어 구분해두었습니다.

3. 유니티 파일을 깃허브에 올리실 때에는 .zip 파일로 압축해서 올려주세요!
